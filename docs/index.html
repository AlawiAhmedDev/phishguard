PhishGuard

Paste a link to see where it really leads and whether it looks like phishing. The model runs in your browser: the link is analysed as text, never opened and never sent anywhere.

Try an example:
A gradient-boosting model reads 32 features of the link (length, subdomains, keywords, brand names, hosting platform...). Links on the 10,000 most visited domains are trusted. It is a learning project and makes mistakes: when in doubt, type the site's address yourself. Source code and evaluation
